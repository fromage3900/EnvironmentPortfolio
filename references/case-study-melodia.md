# Case study — Melodia Melusina portfolio de-fleet

Real run on 2026-08-22. Single-author UE 5.8 + Blender 5.2 rhythm-JRPG / environment-art
portfolio. Owner: "this is not an ai fleet project." Two live GitHub repos under `fromage3900`:
`MelodiaMelusinaV2` (game, in `BS_GodFile/`) and `my-site` (site on GitHub Pages). Local models
(Ollama + Koboldcpp) are real and used as tools.

## What read as "fleet/agent" and what it became

- `package.json` (root): `fleet` / `fleet:qwen` / `fleet:muse` / `fleet:p0` npm scripts →
  `models` / `models:qwen` / `models:muse` / `models:p0`. Underlying `Tools/run_model_fleet.py`
  kept (referenced by `overnight_run.ps1`).
- `wix/melusina-agent-harness.html` → renamed via `git mv` to `wix/melusina-model-tooling.html`.
  Title/og:title/og:url/nav labels updated. Linked from 9 pages (incl. recruiter-facing
  `index.html`, `nvidia-recruiter-sendoff.html`) — so RELABEL, not delete. This page is the
  project's best anti-hype artifact (it withdraws fake "Hermes 3 98.8% AAA" numbers).
- `wix/dashboards.html`, `wix/project_health.html`, `public/melodia/status/index.html`,
  `wix/nous-research-packet.html`, `wix/nvidia-recruiter-sendoff.html`:
  "Hermes harness, Qwen/Muse lanes, SWE Light orchestrator" → "local model tooling (Qwen/Muse)".
- `my-site-clean/README.md`: "Live agent MCP" → "Live bridge"; "first agent ping" →
  "first bridge connection"; "Harness" nav link → "Model Tooling".
- Root `README.md`: "agent lanes" → "local model lanes"; "genome/agent control" → "bridge control".
  Kept the existing "AI tooling is a tool" framing verbatim.

## The reversal (key lesson)

Instruction was "remove the agent-harness page." On checking the link graph it was referenced from 9
pages and held the most honest evidence. Deleting would have broken recruiter links and discarded the
anti-hype proof. Reversed to relabel. Owner accepted.

- Remove the agent page? → No, relabel (preserve evidence + links).
