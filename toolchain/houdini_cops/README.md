# Houdini Copernicus — Sea Above foliage texture bakes + OpenUSD stage

`build_seaabove_foliage_textures.py` bakes BC / N / ORM (R:AO G:Roughness
B:Metallic) / IriMask for the six Sea Above material presets
(`SEAABOVE_KIT_SPEC.md` in `tools/speedtree-audio/`).

```cmd
call ..\houdini_hython\where_hython.cmd
%HYTHON% build_seaabove_foliage_textures.py --res 2048 --out exports\seaabove_textures
```

- Runs the **Copernicus probe** first: when headless COP graph authoring is
  available it reports the node types it found; otherwise it bakes with the
  dependency-free fallback generator (same visual recipe: teal→violet→gold
  thin-film ramp on rims, caustic fbm, droplet/vein height fields).
- The fallback is pure-Python — use `--res 512` for preview, `--res 2048` for
  production (it is slow at 2K; expect minutes per preset).
- Commit only this script; `exports/` stays gitignored like the other toolchain
  caches.

## OpenUSD stage assembly

`build_seaabove_usd_stage.py` composes a `.usda` scene from the baked foliage
kit. It runs under Houdini's hython so it can import Pixar's `pxr` USD module
without any extra pip installs.

```cmd
call ..\houdini_hython\where_hython.cmd
%HYTHON% build_seaabove_usd_stage.py --out exports\seaabove_stage.usda
```

What it produces:
- A `SeaAbove` default prim with a `UsdPreviewSurface` material per preset.
- Each material is wired to the BC / N / ORM / IriMask textures generated by
  `build_seaabove_foliage_textures.py` (ORM channels are split via component
  connections: `outputs:g` for roughness, `outputs:b` for metallic).
- Empty placeholder `Mesh` prims for each preset with a `customData` asset
  pointer to the matching SpeedTree FBX.

This is the "OpenUSD / scene composition" piece of the emerging-3D-architecture
documentation; the stage can be opened in **usdview**, imported into **Blender**, or
pulled into **UE 5 via the USD Stage Editor**.

Or in VS Code:
- **Ctrl+Shift+P → Tasks: Run Task → SeaAbove: Build OpenUSD Stage**.

## Houdini version note

This machine has **Houdini 22.0.368 Apprentice**. The Apprentice license blocks
FBX export via the `filmboxfbx` ROP. The bridge therefore prefers the
**SpeedTree Modeler-exported `.fbx`** that is written next to the `.stmat`; it
only falls back to the Houdini FBX ROP when no vendor FBX exists. For
production work on an Indie/FX license, the fallback will succeed; on
Apprentice, make sure your SpeedTree export includes FBX.
